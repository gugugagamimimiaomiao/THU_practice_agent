# 本地运行数据目录

本目录中的运行时文件不会上传到 GitHub，以避免泄露凭据或真实项目/用户数据。

| 文件或目录 | 生成方式 | 是否应上传 |
|---|---|---|
| `practice_xiaoda.db` | 首次启动 `python3 server.py --port 8765` 自动创建 | 否 |
| `collector_settings.json` | 在“开发者采集”保存配置后产生 | 否，可能包含微信凭据 |
| `collector_audits/` | 公众号采集时产生 | 否，可能包含真实文章内容 |
| `exports/` | 项目库导出时产生 | 否，可能包含真实项目数据 |

协作开发不需要互传上述文件：代码启动后会自动生成一份演示数据库。如需部署生产数据，请由数据负责人通过受控的服务器卷、加密备份或学校认可的存储方式恢复，且不要放到 GitHub。
