# 清小搭浏览器对话测试数据集索引

本目录整理了 2026-08-12 对“实践小搭 · 社会实践决策助手”的浏览器黑盒测试数据。

## 文件

1. `xiaoda_100_turns_readable.md`
   - 正式 100 轮测试的可读版本。
   - 按 20 个连续会话组织，每个会话 5 轮。
   - 包含用户问题、清小搭回答、响应时间、流式状态。

2. `xiaoda_100_turns_raw.jsonl`
   - 与可读版本对应的机器可读数据。
   - 每行一个 JSON 对象。
   - 字段：`n`、`prompt`、`newChat`、`submitted`、`done`、`seenBusy`、`sec`、`response`。

3. `xiaoda_pre100_exploratory_tests.md`
   - 正式采集前 21 轮探索性测试。
   - 逐条标注“完整保留、部分恢复、仅结论”。

## 数据限制

- 正式采集器对每条回答最多保存前 2200 个字符，长列表和长文案可能截断。
- 100 轮中有 52 轮在信息足够判定后，页面流式状态仍未自然结束；`done=false` 记录了这一情况。
- 有 3 轮消息提交后回答区为空，原始记录保留为空字符串。
- 探索性 21 轮发生在统一采集器启用前，不能全部作为逐字转录使用。
- 测试没有导入招募通知、修改项目数据或修改智能体代码。

## 总量

- 正式统一采集：100 轮。
- 前置探索性测试：21 轮。
- 合计：121 轮。
